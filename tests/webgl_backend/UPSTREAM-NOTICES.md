# Upstream notices

This experimental harness downloads the exact revisions in `sources.lock.json`.
The patch adapts Play’s OpenGL renderer and Framework for browser integration.
It retains their BSD licenses. No game executable, ROM, BIOS, capture or save is included.

When redistributing compiled fixtures, include the `licenses` directory produced
by the build script. It contains the licenses for Play, Framework, CodeGen,
ghc_filesystem, zstd and zlib. Downloaded sources retain their own notices.
