## Band-limited audio development checks

The existing worklet, 16-bit ring format and image pool are unchanged. Output capacity is reserved before consuming input; a full ring applies backpressure and can acknowledge pause while blocked. Independent native and Wasm tests include final 16-bit quantization: sampled passband error is 0.001254 dB through 20 kHz, minimum fitted-tone SNR is 83.19 dB, and measured alias rejection is 73.57 dB. Tests verify the peak ceiling, stereo preservation, smooth gain changes, complete tail delivery, invalid-value rejection and no processing allocations. Compiled linear-interpolation and per-channel hard-clipping controls fail the independent fidelity/stereo tests.
